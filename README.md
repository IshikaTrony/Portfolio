# Ishika Trony — Portfolio

A responsive personal portfolio built with HTML, CSS, and a small JavaScript enhancement. No external fonts, dependencies, build step, or credentials are needed.

## Develop locally

From this directory:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

The server serves `index.html`, `styles.css`, and `script.js`. Stop with Ctrl+C. Content is in `index.html`; colors and responsive layouts are in `styles.css`.

## Deployment

These files can be hosted by any static web host, including GitHub Pages. No deployment has been configured or published.

Content is based on the supplied CV. The phone number and CV document are omitted from the public site. The internship uses the CV's January–June 2026 dates rather than describing it as current. The wheelchair project has no repository link because none was provided.
